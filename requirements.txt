# MuseQuotaWidget Python 版依赖：PySide6（Qt 悬浮窗）+ PySide6-WebEngine（登录窗）。
# 不写死版本号：pip 会取与当前平台（macOS arm64 / Windows x64 等）匹配的轮子，
# 避免把某个具体版本写死后在另一台机器上装不上。
# 关键：PySide6 6.12 起已拆包，基础的 PySide6 轮子只有 577KB，不含 WebEngine；
# WebEngine 是单独的 PySide6-WebEngine 包，Mac 上那个轮子约 250MB、
# Windows 约 130MB，装的时候要等一会儿，不要中途打断。
# 只装 PySide6 不装 PySide6-WebEngine 时，主悬浮窗能打开、只显示“未登录”，
# 点登录会报 QtWebEngine 不可用——这就是缺了下面这一行。
